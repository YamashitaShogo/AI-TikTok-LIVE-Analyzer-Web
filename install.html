INSTALL GUIDE

インストール方法

AI TikTok LIVE Analyzer Beta版を Windowsにインストールする手順です。

01

Beta版をダウンロード

最新版のWindows版をダウンロードします。

Windows版を無料ダウンロード

Windows 10 / 11対応 ・ Beta v1.2.0

02

インストーラーを起動

ダウンロードした AI_TikTok_LIVE_Analyzer_Setup_v1.2.0.exe を起動します。

03

セットアップ

画面の案内に従ってインストールを完了します。

04

アプリを起動

AI TikTok LIVE Analyzerを起動します。

05

OBS Studioと接続

OBS Studioを起動し、アプリのOBS設定画面から接続します。
