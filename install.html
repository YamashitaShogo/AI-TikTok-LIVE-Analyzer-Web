INSTALL GUIDE

インストール方法

Livemetry Pulse Beta版を Windowsにインストールする手順です。

01

Beta版をダウンロード

最新版のWindows版をダウンロードします。

Windows版を無料ダウンロード

Windows 10 / 11対応 ・ Beta v1.3.0

02

インストーラーを起動

ダウンロードした LivemetryPulse-Setup-v1.3.0.exe を起動します。

03

セットアップ

画面の案内に従ってインストールを完了します。

04

アプリを起動

Livemetry Pulseを起動します。

05

OBS Studioと接続

OBS Studioを起動し、アプリのOBS設定画面から接続します。

困ったときは

インストールや接続で問題がある場合はこちらからお問い合わせください。
